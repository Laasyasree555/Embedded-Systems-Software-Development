DAY 1
Embedded systems:
A computer system that does a particular task inside a machine or larger electrical system.
Characteristics:
1) Dedicated functionality - Unlike general purpose, performs specific tasks.
2) Real-time operations - respond to changes in input/environment, not the same as "fast".

Operating systems(OS):
- OS is the interface between hardware and software. Eg: H/W - Keyboard S/W - Notepad app, when you type on the keyboard it displays on the notepad it is because of the OS.
- OS performs multitasking such as:
  1) Process Management
  2) Memory Management - RAM, ROM
  3) File Management- As we can see in File Explorer, everything is segregated so that it can be easily accessible and manageable.
  4) Device Management - Keyboard, mouse, CPU, etc
  5) Network Management - WI-FI, Internet
-These are all the fuctions of Kernel
- Simple embedded systems like traffic lights, calculator does not require OS, only complex emebedded systems require OS.
- OS is a software/program
- We can be able to create our own OS
- OS won't stop automatically, unless it crashes or we close the laptop
- Kernel is the core part of OS. Acts as a bridge between software applications and physical Hardware.

- It is open source OS and free - GPL License, no cost

- Secure – Monolithic kernel offering high security
- Scalability – From mobile phone to stock market servers

platform for the success of Open Source

LINUX Properties:
1) Multitasking - Ability to handle multiple tasks across single / multiple processors
2) Multi-user - Have got users with different level of privileges for secured access
3) Protected Memory -  Clear distinction called ‘user-space’ and ‘kernel’ space thereby having protected memory
access. This makes Linux Super secure comparing with other operating systems 
4) Hierarchical File system - Well organized file system that handles various types of files. This also makes handling
various inputs very simple
